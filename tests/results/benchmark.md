# Хугацааны хэмжилт

Энэ файлыг `./bench.sh` автоматаар үүсгэсэн. 3 тусдаа JVM ажиллуулсан. JVM тус бүрд 3 дулаацуулах ажиллалтын дараа 9 удаа хэмжиж медианыг авсан. Хүснэгтэд тэдгээр 3 медианы **медиан**-ыг (ms) харуулав. Хаалтанд 3 thread-ийн хугацааны JVM хоорондын min–max мужийг өгөв. Оролт: санамсаргүй int (seed = 1). Trace унтраалттай.

- **1 thread:** нэг thread бүх массивыг ижил алгоритмаар эрэмбэлнэ (харьцуулах суурь).
- **1 thread, хувааж:** номын бүтэцтэй ижил ажлыг (зүүн хэсэг, баруун хэсэг, нэгтгэл) нэг thread дараалан хийнэ.
- **3 thread:** номын бүтэц (2 sorting thread + 1 merging thread, parent join хийнэ).
- **Нийт хурдсалт** = 1 thread / 3 thread.
- **Зэрэгцээний хурдсалт** = 1 thread хувааж / 3 thread, өөрөөр хэлбэл хоёр хэсгийг зэрэг ажиллуулснаас олсон ашиг.
