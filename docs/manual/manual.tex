\msec{8.1 Хэрэглэгчийн заавар}

\msub{Програмын зорилго}
Бүхэл тоон жагсаалтыг гурван бодит Java thread-ээр эрэмбэлнэ. Parent thread жагсаалтыг
\code{[0, mid)} ба \code{[mid, n)} хоёр хэсэгт хуваана ($mid = \lceil n/2\rceil$). Хоёр sorting thread
(\textbf{Sorter-L}, \textbf{Sorter-R}) өөр өөрийн хэсгийг зэрэг эрэмбэлнэ. Дараа нь \textbf{Merger} thread
хоёр хэсгийг хоёр дахь global массив \code{result[]} руу нэгтгэнэ. Parent бүх thread-ийг \code{join()}
хийгээд үр дүнг хэвлэнэ. Web UI нь бодит thread-ийн үйлдэл бүрийг баганан animation-аар харуулна.

\msub{Дэмжих орчин}
\begin{itemize}
  \item \textbf{JDK 17} буюу түүнээс дээш (\code{javac} хэрэгтэй, зөвхөн JRE хангалтгүй).
  \item macOS, Linux эсвэл Windows. Web UI-д Chrome, Edge, Firefox, Safari-ийн сүүлийн хувилбар.
  \item Гадны сан, Maven, Gradle, интернэт холболт шаардлагагүй.
\end{itemize}

\msub{Суулгах / нээх алхам}
\begin{itemize}
  \item JDK 17 суулгана: macOS дээр \code{brew install --cask temurin@17}, Ubuntu дээр
        \code{sudo apt install openjdk-17-jdk}, Windows дээр \url{https://adoptium.net}-аас Temurin 17.
  \item Repository-г clone хийж эсвэл ZIP-ийг задлаад төслийн хавтас руу Terminal-аар орно.
  \item \code{javac -version} командаар \code{javac 17.x} гарч байгааг шалгана.
  \item \code{./build.sh} (Windows: \code{build.bat}) ажиллуулна. \code{Build OK (javac 17) -> out/} гарвал бэлэн.
  \item \code{./run.sh --web} ажиллуулж, хөтөч дээр \url{http://localhost:8080} хаягийг нээнэ.
\end{itemize}

\msub{Оролт ба тохиргоо}
\begin{itemize}
  \item \textbf{Тоонууд:} бүхэл тоонуудыг таслал эсвэл зайгаар тусгаарлана. Жишээ: \code{7, 12, 19, 3, 18}.
        Сөрөг тоо, давхардсан утга, сондгой n зөвшөөрнө.
  \item \textbf{Гараар / Санамсаргүй:} санамсаргүй үед n, Seed, Min, Max, Хэлбэр (random, sorted, reversed,
        duplicates)-ийг тохируулна.
  \item \textbf{Алгоритм:} Sorter-L ба Sorter-R тус бүрт insertion, bubble, selection, merge, quick-ээс сонгоно.
  \item \textbf{Горим:} \textbf{Replay}: Java дээр thread-үүд ажиллаж дуусаад, бүртгэсэн event-ийг урагш/хойш
        тоглуулна (n $\le$ 300). \textbf{Lockstep}: thread-үүд амьд байж, алхам бүрд Semaphore-ийн permit хүлээнэ (n $\le$ 100).
  \item \textbf{CLI:} \code{./run.sh --input "7,12,19,3"}, \code{--file PATH}, \code{--random N --seed S},
        \code{--algo-left NAME --algo-right NAME}, \code{--help}.
\end{itemize}

\msub{Ажиллуулах, зогсоох, reset хийх}

Thread-ийн карт дээр төлөв гарна: \emph{Үүсээгүй → start() дуудагдсан → Ажиллаж байна → Дууссан}, Parent-д
\emph{join() дээр хүлээж байна}. Lockstep горимд Java-гийн бодит төлөв (\code{NEW}, \code{RUNNABLE},
\code{WAITING}, \code{TERMINATED}) нэмж харагдана.

\msub{Хоёроос доошгүй жишээ}
\textbf{Жишээ 1 — Номын жишээ (Web UI, Replay)}
\begin{itemize}
  \item “Номын жишээ” товч: \code{7, 12, 19, 3, 18, 4, 2, 6, 15, 8}. Sorter-L = insertion, Sorter-R = merge.
  \item “Ажиллуулах”, дараа нь “Алхам ▸” дарж хоёр хэсэг эрэмбэлэгдэж, Merger нэгтгэхийг ажиглана.
  \item Хүлээгдэх үр дүн: \code{[2, 3, 4, 6, 7, 8, 12, 15, 18, 19]}, Шалгалт: “Эрэмбэлэгдсэн, зөв”.
\end{itemize}
\textbf{Жишээ 2 — Сондгой n, өөр алгоритм (CLI)}
\begin{itemize}
  \item \code{./run.sh --file examples/odd-11.txt --algo-left bubble --algo-right quick}
  \item Хуваалт: зүүн 6, баруун 5 элемент. Хүлээгдэх үр дүн: \code{[1, 2, \dots, 11]}, ЗӨВ.
\end{itemize}
\textbf{Жишээ 3 — Lockstep горим}
\begin{itemize}
  \item Горим = Lockstep, “Ажиллуулах” дарна. Sorter-уудын карт дээр \code{WAITING} гарна.
  \item “Алхам ▸” бүрд нэг thread яг нэг үйлдэл хийнэ, хоёр sorter ээлжилнэ. Төгсгөлд бүгд \code{TERMINATED}.
\end{itemize}

\msec{8.2 Operational заавар}

\msub{Repository clone хийх}
\begin{cmd}
git clone https://github.com/Munkhgerelt/F.CSM302-TeamProject-2-4-6.git
cd F.CSM302-TeamProject-2-4-6
\end{cmd}

\msub{OS, compiler/runtime, хувилбар}
JDK 17 буюу түүнээс дээш (\code{javac -version}); \code{build.sh} нь \code{javac --release 17} ашигладаг.
Туршсан орчин: macOS 27 (Apple Silicon) + Temurin 17.0.21, Ubuntu 24.04 (amd64) + OpenJDK 21.

\msub{Dependency суулгах}
Гадны dependency байхгүй: зөвхөн JDK хэрэгтэй. Web сервер нь JDK-д багтсан \code{com.sun.net.httpserver}.

\msub{Build ба Run команд}
\begin{cmd}
./build.sh && ./run.sh --file examples/book-example.txt
./run.sh --web
\end{cmd}
Windows: \code{build.bat}, \code{run.bat --web}. Скрипт ажиллахгүй бол \code{chmod +x *.sh}. Хөрвүүлсэн
файлууд \code{out/}-д гарна (commit хийгдэхгүй).

\msub{Үндсэн тестийн өгөгдөл}
\code{examples/} хавтас: \code{book-example.txt} (номын жишээ), \code{odd-11.txt}, \code{duplicates.txt},
\code{reversed.txt}, \code{int-limits.txt}, \code{single.txt}; алдаатай: \code{invalid-letters.txt},
\code{invalid-overflow.txt}, \code{empty.txt}. Автомат тест: \code{./test.sh} (Windows: \code{test.bat}),
JUnit-гүй 100 тест (\code{tests/TestRunner.java}). Хугацааны хэмжилт: \code{./bench.sh}.

\msub{Нэмэлт boundary/error тест}
\begin{itemize}
  \item Нэг элемент: \code{./run.sh 42} → \code{[42]} (баруун хэсэг хоосон). Хоёр элемент: \code{./run.sh 2 1} → \code{[1, 2]}.
  \item Давхардсан: \code{--file examples/duplicates.txt} → \code{[1, 1, 1, 2, 2, 3, 3, 3, 3, 5, 5, 5]}.
  \item Хязгаар: \code{--file examples/int-limits.txt} → \code{-2147483648} ба \code{2147483647} зөв байрлана.
  \item Алдаатай оролт: \code{--input ""}, \code{--input "5,3,abc"}, \code{--input "1,2.5"} → алдааны мессеж, exit code 2.
\end{itemize}

\msub{Хүлээгдсэн үр дүн}
Номын жишээ: \code{[2, 3, 4, 6, 7, 8, 12, 15, 18, 19]}, \code{Шалгалт: ЗӨВ}, exit code 0. Автомат тест:
\code{Нийт: 100, амжилттай: 100, алдаатай: 0}. Тест бүрийн оролт, хүлээгдсэн ба бодит утга
\code{tests/results/test-results.md}-д, хэмжилт \code{tests/results/benchmark.md}-д бичигдэнэ.

\msub{Known issues}
\begin{itemize}
  \item Windows-ийн \code{.bat} скриптийг бодит Windows машин дээр туршаагүй.
  \item n бага үед хугацааны хэмжилт шуугиантай (JIT, thread үүсгэх зардал); trace-тэй ажиллалт удаан.
  \item Lockstep-д хойш алхах боломжгүй; Web сервер зөвхөн \code{127.0.0.1} дээр сонсоно.
\end{itemize}
