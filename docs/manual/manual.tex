\section{Хэрэглэгчийн заавар}

Энэ бүлэгт программын зорилго, дэмжих орчин, суулгах алхам, Web UI-ийн удирдлага, дүрслэлийн утга
болон түгээмэл алдааны шийдлийг хэрэглэгчийн ажиллах дарааллаар тайлбарлана.

\subsection{Программын зорилго}

Программ нь бүхэл тоон жагсаалтыг бодит Java \term{thread}-үүдээр эрэмбэлж, энэ ажиллагааг алхам алхмаар
харуулдаг. Даалгавар нь \emph{Operating System Concepts} номын 4-р бүлгийн Programming Project дээр үндэслэсэн~[1].
Parent \term{thread} жагсаалтыг \code{[0, mid)} ба \code{[mid, n)} хоёр хэсэгт хуваана ($mid = \lceil n/2\rceil$).
Sorter-L ба Sorter-R өөр өөрийн хэсгийг зэрэг эрэмбэлж, дараа нь Merger хоёр хэсгийг \code{result[]} массив руу нэгтгэнэ.
Энэ дарааллыг Зураг~\ref{fig:fj}-д харуулав.

\begin{figure}[H]
  \centering
  \includegraphics[width=\linewidth]{../../report/bd2/figures/fig2-fork-join.png}
  \caption{Parent, хоёр sorting thread ба merging thread-ийн ажиллах дараалал.}
  \label{fig:fj}
\end{figure}

Зурагт цэнхэр хүрээ нь \term{thread} ажиллаж буй үеийг, тасархай хүрээ нь Parent \code{join()} дээр хүлээж буй
үеийг заана. Merger хоёр \term{sorter} дууссаны дараа л эхэлдэг тул эрэмбэлсэн утгуудыг зөв уншина.

\subsection{Дэмжих орчин}

Программыг ажиллуулахад дараах орчин шаардлагатай. Гадны сан, Maven, Gradle болон интернэт холболт хэрэггүй.

\begin{itemize}
  \item JDK 17 буюу түүнээс дээш хувилбар (\code{javac} шаардлагатай, зөвхөн JRE хангалтгүй).
  \item macOS, Linux эсвэл Windows үйлдлийн систем.
  \item Web UI-д Chrome, Edge, Firefox эсвэл Safari хөтчийн сүүлийн хувилбар.
\end{itemize}

\subsection{Суулгах ба нээх алхам}

Программыг анх удаа ажиллуулах бүрэн урсгалыг Зураг~\ref{fig:flow}-д харуулав. Эхний эгнээ нь суулгах, ажиллуулах
алхмыг, хоёр дахь эгнээ нь Web UI дээрх тохиргоог, сүүлийн эгнээ нь сонгож болох хоёр горимыг заана.

\begin{figure}[H]
  \centering
  \includegraphics[width=\linewidth]{../../report/bd2/figures/fig5-usage-flow.png}
  \caption{Программыг суулгаж, Web UI дээр ажиллуулах урсгал.}
  \label{fig:flow}
\end{figure}

Зурагт үзүүлсэн алхмуудыг дараах дарааллаар гүйцэтгэнэ.

\begin{enumerate}
  \item JDK 17 суулгана: macOS дээр \code{brew install --cask temurin@17}, Ubuntu дээр
        \code{sudo apt install openjdk-17-jdk}, Windows дээр \url{https://adoptium.net} хаягаас Temurin 17.
  \item Төслийн хавтас руу Terminal-аар орж, \code{javac -version} командаар хувилбарыг шалгана.
  \item \code{./build.sh} (Windows: \code{build.bat}) ажиллуулна. \code{Build OK (javac 17) -> out/} гарвал бэлэн.
  \item \code{./run.sh --web} ажиллуулж, хөтөч дээр \url{http://localhost:8080} хаягийг нээнэ.
\end{enumerate}

\subsection{Оролт ба тохиргоо}

Web UI болон командын мөрөөр дараах тохиргоог өөрчилж, программыг дахин ажиллуулж болно.

\begin{itemize}
  \item \textbf{Тоонууд:} бүхэл тоонуудыг таслал, цэг таслал эсвэл зайгаар тусгаарлана, жишээ нь \code{7, 12, 19, 3, 18}.
        Сөрөг тоо, давхардсан утга, сондгой n зөвшөөрөгдөнө. \code{1,,2} эсвэл \code{1,2,} гэх мэт хоосон утгыг алгасаж,
        энэ тухай тэмдэглэл гаргана.
  \item \textbf{Санамсаргүй өгөгдөл:} n, \term{seed}, хамгийн бага, хамгийн их утга болон хэлбэрийг
        (\term{random}, \term{sorted}, \term{reversed}, \term{duplicates}) сонгоно.
  \item \textbf{Алгоритм:} Sorter-L, Sorter-R тус бүрт \term{insertion}, \term{bubble}, \term{selection},
        \term{merge}, \term{quick} алгоритмаас сонгоно.
  \item \textbf{Горим:} \term{Replay} горимд \term{thread}-үүд ажиллаж дууссаны дараа бүртгэсэн \term{event}-ийг урагш, хойш
        тоглуулна (n $\le$ 300). \term{Lockstep} горимд амьд \term{thread}-үүд алхам бүрд \term{Semaphore}-ийн \term{permit} хүлээнэ (n $\le$ 100).
  \item \textbf{Командын мөр:} \code{--input "7,12,19,3"}, \code{--file PATH}, \code{--random N --seed S},
        \code{--algo-left NAME}, \code{--algo-right NAME}, \code{--help}.
\end{itemize}

\subsection{Ажиллуулах жишээ}

Программын гол боломжийг шалгах гурван жишээг доор өгөв. Жишээ бүрт хийх үйлдэл ба хүлээгдэх үр дүнг бичсэн.

\begin{enumerate}
  \item \textbf{Номын жишээ (Web UI, \term{Replay}).} «Номын жишээ» товч дарж, Sorter-L-д \term{insertion}, Sorter-R-д \term{merge} сонгоод
        «Ажиллуулах» дарна. Хүлээгдэх үр дүн: \code{[2, 3, 4, 6, 7, 8, 12, 15, 18, 19]}.
  \item \textbf{Сондгой n (командын мөр).} \code{./run.sh --file examples/odd-11.txt --algo-left bubble --algo-right quick}
        командыг ажиллуулна. Зүүн хэсэгт 6, баруун хэсэгт 5 элемент орж, \code{[1, 2, \dots, 11]} гарна.
  \item \textbf{\term{Lockstep} горим.} Горимыг \term{Lockstep} болгож «Ажиллуулах» дарна. «Алхам \stepfwd» дарах бүрд нэг \term{thread} нэг үйлдэл хийж,
        төгсгөлд бүх \term{thread} \code{TERMINATED} төлөвт орно.
\end{enumerate}

\section{Operational заавар}

Энэ бүлэгт программыг өөр компьютер дээр дахин бүтээх, ажиллуулах, шалгахад шаардлагатай техникийн мэдээллийг өгнө.

\subsection{Repository clone хийх}

Эх кодыг GitHub-аас дараах командаар татаж авна.

\begin{cmd}
git clone https://github.com/Munkhgerelt/F.CSM302-TeamProject-2-4-6.git
cd F.CSM302-TeamProject-2-4-6
\end{cmd}

\subsection{OS, compiler, runtime хувилбар}

Төслийг JDK 17 буюу түүнээс дээш хувилбараар хөрвүүлнэ. \code{build.sh} нь \code{javac --release 17} ашигладаг.
БД2-ын эцсийн хувилбарыг macOS 27 (Apple M4), Temurin 17.0.21 орчинд туршсан. БД1-ийн хувилбарыг мөн Ubuntu 24.04 (amd64),
OpenJDK 21 дээр туршсан бөгөөд БД2-ын хувилбарыг Linux дээр дахин туршаагүй.

\subsection{Dependency суулгах}

Төсөл гадны \term{dependency}-гүй тул JDK-аас өөр зүйл суулгах шаардлагагүй. Web сервер нь JDK-д багтсан
\code{com.sun.net.httpserver} санг ашигладаг.

\subsection{Build ба Run команд}

Программыг хөрвүүлж, номын жишээг ажиллуулаад Web UI-г дараах командаар эхлүүлнэ.

\begin{cmd}
./build.sh
./run.sh --file examples/book-example.txt
./run.sh --web
\end{cmd}

Windows дээр \code{build.bat}, \code{run.bat --web} скриптийг ашиглана. Скрипт ажиллахгүй бол \code{chmod +x *.sh} командыг
ажиллуулна. Хөрвүүлсэн файлууд \code{out/} хавтаст гарна.

Номын жишээг ажиллуулахад \code{[2, 3, 4, 6, 7, 8, 12, 15, 18, 19]}, \code{Шалгалт (Arrays.sort-той харьцуулав): ЗӨВ} гэж гарч,
exit code 0 буцна. Автомат тестийн төгсгөлд \code{Нийт: 114, амжилттай: 114, алдаатай: 0} гэж гарна. Тест бүрийн оролт,
хүлээгдсэн ба бодит утга \code{tests/results/test-results.md} файлд, хугацааны хэмжилт \code{tests/results/benchmark.md} файлд бичигдэнэ.

\subsection{Known issues}

Эцсийн хувилбарын мэдэгдэж буй хязгаарлалт дараах байдалтай байна.

\begin{itemize}
  \item Windows-ийн \code{.bat} скриптийг бодит Windows машин дээр туршаагүй.
  \item n бага үед хугацааны хэмжилтэд JIT болон \term{thread} үүсгэх зардал нөлөөлнө.
  \item \term{Lockstep} горимд хойш алхах боломжгүй. Web сервер зөвхөн \code{127.0.0.1} хаягаар сонсдог.
  \item Зэрэг 4 хүртэл \term{Lockstep} \term{session} ажиллана. 5 дахь нь эхлэхэд хамгийн удаан идэвхгүй байсан
        \term{session} хаагдаж, тухайн цонхонд шалтгаан нь гарна. 10 минут идэвхгүй \term{session} мөн хаагдана.
\end{itemize}
